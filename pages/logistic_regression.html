Logistic Regression

Logistic regression is a widely used classification model capable to estimate how many probabilities a sample it’s like to belong to a class (which is essential, for example, to do medical predictions or weather forecasting).
Everything starts from the logit function which takes as input values ranging in \( [0,1] \) and returns some number \( n \in \mathbb{R} \); this is useful to create a linear relation between an attribute value and log-odds.
\[\text{logit}(p) = log \frac{p}{(1-p)}\]
What we would want to discover is \(P(y=1 | x;w)\) which is the conditional probability of a chosen sample to belong to class 1, given it's attributes \(x\) parametrized by weigths \(w\).
\[ \text{logit}(P(y=1|x;w)) = \sum^{n}_{i=0}w_mx_m = w^Tx = z \] \[ \text{logit}(P(y=1|x;w))^{-1} = \phi(z) = \frac{1}{1+e^{-z}} \]
Where \(\phi(z)\) is said to be the sigmoid function (plotted) which takes as input value some real value mapping it to \([0, 1]\) and intersecting \(y\)-axis when \(z\) is \(0\).
Some predicted probability can be converted into a binary value by a unit-step function.
\[ \hat{y} = \left\{\begin{array}{@{}l@{}} 1 & \textrm{if $z=0$}\\ 0 & \textrm{otherwise} \end{array}\right.\, \]
What we want to do now is to find a method to generate the "optimal sigmoid" to fit our data. Let’s find a cost function: we can both maximize \(l(w)\) or minimize \(J(w)\).
\[L(w) = P(y|x;w) = \prod^{n}_{i=1}P(y^{(i)} | x^{(i)};w) = \prod^{n}_{i=1} (\phi(z^{(i)}))^{y^{(i)}} (1-\phi(z^{(i)}))^{1-y^{(i)}} \] \[l(w) = log(L(w)) = \sum^{n}_{i=1} y^{(i)}(\phi(z^{(i)})) + (1-y^{(i)})(1-\phi(z^{(i)})) \] \[J(w) = \sum^{n}_{i=1} -y^{(i)}\left(\phi(z^{(i)})\right) - (1-y^{(i)})\left(1-\phi(z^{(i)})\right) \]
By applying \(log\) function we reduce the probabilities to have a numerical underflow
This is also a smart way to keep our mental stability while derivating.
Let's consider a single sample and see how weights are fixed depending on how bad a misclassification is.
\[ J(\phi(z), y;w) = -y(\phi(z)) - (1-y)(1-\phi(z)) \] \[ J(\phi(z), y;w) = \left\{\begin{array}{@{}l@{}} -log(\phi(z)) & \textrm{if $y = 1$}\\ -log(1-\phi(z)) & \textrm{if $y = 0$} \end{array}\right.\, \]

Of course an highly optimized version of Logistic Regression is already implemented for us. What we are about to do is study the relation between breast-cancer mean radius and it's danger. As you can read in the documentation the attributes are various, such as "number of concave portions of the contour", but now we only focus on one feature. Every binary classifier, LogisticRegression included, could be extended using OvR. 
                    
                        import pandas as pd
                        import matplotlib.pylab as plt
                        import numpy as np

                        from sklearn.linear_model import LogisticRegression
                        from sklearn.model_selection import train_test_split # see
                        from sklearn.datasets import load_breast_cancer

                        cancer = load_breast_cancer()
                        df = pd.DataFrame(data=cancer.data, columns=cancer.feature_names)[['mean radius']]
                        df['target'] = cancer.target

                        X_train, X_test, y_train, y_test = train_test_split(df[['mean radius']].values, df['target'].values, test_size=0.3, random_state=42)
                        
                        lr = LogisticRegression(C=1.0)
                        lr.fit(X_train, y_train)
The model is now trained. Since we divided the initial dataset in a train and a test set, we can use the latter to better visualize what the theory says. 
                    
                        # Does predicted value match the corresponding target? Oh, then draw a green circle please!
                        for i in range(len(X_test)):
                            plt.scatter(X_test[i], y_test[i], linewidths=0, color=('green' if lr.predict([X_test[i]]) == y_test[i] else 'red') )

                        # Estimating a probability for each x in our domain should give a sigmoid
                        probs = []
                        rads = np.arange(min(X_test), max(X_test), 0.01)
                        for r in rads:
                            p_loss, p_win = lr.predict_proba([[r]])[0]
                            probs.append(p_win)
                        plt.plot(rads, probs)

Regularization

If you read the above code, you probably noticed a mysterious parameter \(C\). It is an hyperparameter used to specify how strong regularization is; this is fundamental to find a good compromise between underfitting and overfitting.
When a model behaves super for a given dataset but fails to cope with new data, then it doesn’t really learned something valuable; it knows the dataset but it didn’t get not the theory underlying it so it’s said to be overfitted.
Ideally, one wants to choose a model that both accurately captures the regularities in its training data, but also generalizes well to unseen data. Unfortunately, it is typically impossible to do both simultaneously. This is also known as
bias / variance tradeoff.
To resolve this compromise we need to use some regularization techniques to reduce data noise, manage multicollinearity and avoid overfitting, by introducing new informations (bias) thus penalize extreme weights in the model.
When applying regularization it is fundamental for the attributes to be scaled to the same range. Remember when we normalized our dataset, while learning Adaline?
One of the most common techniques is L2 which can be write as the following.
\[ \frac{\lambda}{2} ||w^2|| = \frac{\lambda}{2} \sum^{m}_{j=1}(w_j^2) \]
We just need to add the regularization parameter \(\lambda\) to the previous cost function.
\[ J(w) = \left[ \sum^{n}_{i=1} -y^{(i)}\left(\phi(z^{(i)})\right) - (1-y^{(i)})\left(1-\phi(z^{(i)})\right) \right] + \frac{\lambda}{2} \sum^{m}_{j=1}(w_j^2) \]
